### 🙋 Who I am
I'm Petr Kalinkin, a second-year full-time student at **ITMO University** (Saint Petersburg) studying information security of telecommunication systems.
Since June 2025 I've been working as an **information security specialist and Linux administrator** at a telecom company, so I learn security not only from lectures but from real alerts, real servers and real users.

### 🛠️ What I do
- **Security operations:** monitoring events in **SIEM/EDR**, first-line triage and escalation of incidents, reviewing vulnerability scanner results (Nessus, OpenVAS), access-rights audits, supporting IAM/MFA.
- **Linux administration:** day-to-day work with Kali, Arch and Fedora, networking and virtualization.
- **Low-level programming:** I write C and read assembly (NASM) to understand how software works under the hood — packers, memory, processes, randomness.
- **Python tools:** scanners, automation scripts and small learning apps.
- Participant of the **Alfa-Bank hackathon** (Альфа-хакатон).
